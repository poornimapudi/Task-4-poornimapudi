# General Knowledge Quiz Game

## Description

The General Knowledge Quiz Game is a simple command-line project developed using Python that tests a user's general knowledge through a series of questions. The application presents multiple-choice or direct-answer questions, checks the user's responses, and awards one point for each correct answer. At the end of the quiz, the program displays the final score along with a performance message based on the user's results.

This project demonstrates the use of Python fundamentals such as variables, user input handling, conditional statements, score tracking, and program flow control. It provides an interactive way to assess knowledge while strengthening basic programming concepts.

## Features

* Interactive quiz experience
* Multiple general knowledge questions
* Automatic answer validation
* Score calculation and tracking
* Instant feedback for each answer
* Final performance evaluation
* User-friendly command-line interface

## Technologies Used

* Python 3

## Learning Outcomes

Through this project, I gained practical experience with:

* Variables and data storage
* User input handling
* Conditional statements (`if-else`)
* Score tracking using counters
* String comparison and manipulation
* Program flow control

## Conclusion

This General Knowledge Quiz Game is a beginner-friendly Python project that provides an engaging way to test knowledge while strengthening core programming concepts such as user interaction, decision-making, and score management.
